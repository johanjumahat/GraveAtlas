# Phase 16 Roadmap

**Date:** 2026-08-11

## NOW (Implemented)
- AI-native home screen with command bar and suggested prompts
- AI research assistant system prompt (evidence-first, no fabrication)
- Evidence-first badge system (6 categories with colors)
- Smart record cards (cemetery list + grave detail with evidence badges)
- Contextual actions on grave records (Explain, Show Sources, Find Related, View on Map, Check Provenance, Report)
- Prefill question from home screen to AI chat
- Design system updated with evidence colors and AI UI tokens

- Perform TalkBack screen reader testing
- Test with large text settings
- Add "Why am I seeing this?" transparency feature
- Make AI command bar persistent across all screens
- Add research session persistence (save investigations)

- Multimodal research (photo upload, OCR, document scanning)
- Desktop GUI (split-screen research layout)
- Full voice navigation from any screen
- AI transparency dashboard
