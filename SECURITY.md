# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest release on `main` | ✅ |
| Older versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in GraveAtlas, please report it **privately** rather than opening a public issue.

**How to report:**
1. Use [GitHub's private vulnerability reporting](https://github.com/putraworks2026/GraveAtlas/security/advisories/new) — click "Report a vulnerability" on the Security tab.
2. Or email: **security@putraworks-2026.workers.dev** with a description of the issue and reproduction steps if applicable.

**Response time:** We aim to acknowledge reports within 48 hours and provide a fix timeline after initial assessment.

**Please do NOT:**
- Open a public GitHub issue for security vulnerabilities.
- Post exploit details in public channels (Discussions, PRs, etc.).

## Scope

- GraveAtlas Android app (this repository)
- GraveAtlas Cloudflare Worker backend (this repository)
- GraveAtlas data repository (`graveatlas-data`)

Out of scope: third-party services we depend on (GitHub API, Cloudflare) — report those to the respective provider.

## Recognition

We appreciate responsible disclosure and will credit reporters in release notes if they wish.
